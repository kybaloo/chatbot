## 🚀 Devenir contributeur

### 1. Première contribution

1. **Fork** le repository
2. **Clone** votre fork
3. **Créer une branche** feature
4. **Faire vos modifications**
5. **Tester** vos changements
6. **Soumettre** une Pull Request

### 2. Contributeur régulier

Après plusieurs contributions acceptées :
- Accès en écriture au repository
- Possibilité de reviewer les PRs
- Participation aux décisions d'architecture

### 3. Mainteneur

Les mainteneurs sont choisis parmi les contributeurs réguliers basé sur :
- Qualité des contributions
- Connaissance du projet
- Engagement à long terme
- Compétences techniques

## 📝 Code de conduite

Tous les contributeurs doivent respecter notre [Code de Conduite](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).

### Valeurs

- **Respect** : Traiter tout le monde avec dignité
- **Inclusion** : Accueillir toutes les perspectives
- **Collaboration** : Travailler ensemble efficacement
- **Qualité** : Viser l'excellence dans le code et la documentation
